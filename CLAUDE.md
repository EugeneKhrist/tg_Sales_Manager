# CLAUDE.md

## О проекте
Telegram-бот выдуманного турагентства «Поехали с нами» (Экибастуз, Казахстан). Бот в диалоге с клиентом через бесплатную модель OpenRouter выясняет пожелания к поездке, собирает заявку и присылает её владельцу в личный Telegram. Учебное задание по промпт-инжинирингу: главное — качество `system_prompt.md`.

## Стек
- Node.js 18+ (проверено на Node 26), **без внешних зависимостей** (`npm install` не нужен): встроенный `fetch`, свой мини-клиент Telegram, long polling.
- OpenRouter (`/chat/completions`), бесплатные модели `:free`, цепочка «основная → запасные».
- Хранение заявок: `leads.json` (локальный файл, в git не попадает).

## Как запускать
```
npm start        # запуск бота (node index.js)
npm test         # проверки логики заявок (node --test)
```
Перед запуском скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `OPENROUTER_API_KEY`, `ADMIN_CHAT_ID`.

## Структура
- `index.js` — точка входа, проверка .env.
- `system_prompt.md` — system prompt (читается при каждом запросе: правки видны без перезапуска).
- `src/bot.js` — команды, кнопки, диалог, подтверждение и отправка заявки.
- `src/leads.js` — поля заявки, проверка данных, сводка, `leads.json`.
- `src/openrouter.js` — запросы к моделям, переключение на запасную, разбор JSON.
- `src/telegram.js` — клиент Telegram Bot API.
- `src/directions.js` — направления для `/directions` (данные в коде).
- `src/config.js` — загрузка .env, список моделей, данные агентства.
- `tests/` — тесты на `node:test`.

## Как работает сбор заявки
Модель в каждом ответе возвращает JSON `{reply, fields, confirmed}`. **Код** (а не модель) проверяет и сохраняет поля (`mergeFields`), сам решает, что заполнено (`missingFields`), сам показывает сводку и сам отправляет заявку после подтверждения. Телефон принимается, только если его цифры реально встречались в сообщениях клиента.

## Правила
- **Ключи и токены — только в `.env`.** Никогда не писать их в код, README, логи, чат и коммиты; не выводить их в консоль.
- `.env` и `leads.json*` должны оставаться в `.gitignore`. Перед каждым коммитом проверять `git ls-files`.
- Не отправлять репозиторий на GitHub без явной просьбы владельца.
- При изменении направлений, цен-ориентиров, адреса или часов работы правьте **оба места**: `system_prompt.md` и `src/directions.js` / `src/config.js`.
- Бот не называет точных цен, не обещает места, визы и скидки, не принимает оплату и данные карт/паспортов — эти правила нельзя ослаблять в промпте.
- Менять список моделей можно в `src/config.js` (`DEFAULT_MODELS`) или переменной `MODELS` в `.env` (через запятую).
